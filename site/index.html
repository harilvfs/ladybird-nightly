A NOTE BEFORE YOU BROWSE

Early software.
Real rough edges.

Ladybird is an independent browser project, and these community builds track upstream development. Expect bugs, crashes, and websites that may not work as expected.

This project is not affiliated with or endorsed by Ladybird. The Ubuntu and Fedora packages follow upstream build dependencies. Arch packaging is maintained here and may need changes as upstream evolves. Compatibility with derivative distributions is not guaranteed.
