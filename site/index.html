QUICK START

One command.
Latest nightly.

The installer supports Ubuntu 26.04, Fedora 44, Arch Linux, and Arch-based distributions. On other distributions it stops because no package is available.

After installation, run ladybird or lb. The lb command is quiet and works well from app launchers.

TERMINAL
curl -fsSL https://raw.githubusercontent.com/harilvfs/ladybird-nightly/main/install.sh | bash
Then launch ladybird from your app launcher or terminal.
Uninstall Ladybird Nightly
TERMINAL
curl -fsSL https://raw.githubusercontent.com/harilvfs/ladybird-nightly/main/install.sh | bash -s -- --uninstall
Removes the installed distro package and older local launcher files.
PLATFORM NOTES

Know what
to expect.

Packages are tested on the mainline distributions listed above. Compatibility with their derivatives is not guaranteed.

Ubuntu and Fedora

These packages follow Ladybird upstream's build dependencies. The Ubuntu package may not work on Debian, which can ship older Qt and glibc versions.

Arch Linux

Upstream does not directly support Arch Linux. I maintain the Arch dependency mapping and packaging. Upstream changes may require updates, so compatibility can change.

i
Important

Derivative distributions: Ubuntu-based, Fedora-based, and Arch-based distributions are not guaranteed to work. If you run into a problem, open an issue with your distro, version, and error.

KNOWN UPSTREAM ISSUES

HTTPS certificate error 77

On some distributions, including Arch, openSUSE, and NixOS, certificate symlinks can point outside paths available to Ladybird's sandbox. HTTPS requests may fail with a CA certificate error. See upstream issue 10241.

Crashes on older CPUs

Some older CPUs, including Intel Haswell and earlier, may hit an illegal instruction crash in WebContent. Related upstream reports: 8989, 3836, and 10298.

i

Note Standalone tarballs are paused because they have had issues across Linux distributions, and maintaining separate fixes without upstream support for each distribution is not practical. Distro packages are built from upstream master daily at 02:00 UTC. Builds can fail when upstream code or dependencies change. If the latest release is several days old, the package build may be failing.

A NOTE BEFORE YOU BROWSE

Early software.
Real rough edges.

Ladybird is an independent browser project. These unofficial community builds may contain bugs, may crash, or may fail to work with some websites. Do not use them for sensitive browsing.

This project is not affiliated with or endorsed by Ladybird. Change the browser's appearance in its own settings. Old Qt theme environment overrides from earlier builds no longer apply. Browser engine issues belong in the upstream project. Use this project's issues for packaging, install, or distribution problems.
