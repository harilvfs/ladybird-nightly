# Ladybird Nightly

Unofficial Linux x86_64 nightly packages for the [Ladybird browser](https://github.com/LadybirdBrowser/ladybird).

Visit the [Ladybird Nightly site](https://harilvfs.github.io/ladybird-nightly/) for downloads, installation instructions, supported distributions, compatibility notes, and known issues.

These are early community builds. Bugs, crashes, and website compatibility issues are expected. Do not use them for sensitive browsing.

Report browser engine issues to [Ladybird](https://github.com/LadybirdBrowser/ladybird/issues). Report packaging, installer, or distribution issues in [this repository's issues](https://github.com/harilvfs/ladybird-nightly/issues).
